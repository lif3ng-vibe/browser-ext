# Triage 标签

技能用五个标准 triage 角色对话。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 里的标签 | 本仓库标签           | 含义                                     |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue                  |
| `needs-info`               | `needs-info`         | 等报告者补充信息                          |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整,可以交给 AFK agent 实现         |
| `ready-for-human`          | `ready-for-human`    | 需要人来实现                              |
| `wontfix`                  | `wontfix`            | 不做                                      |

另有一个 triage 体系之外的本仓库专用标签:

| 标签   | 含义                                                                 |
| ------ | -------------------------------------------------------------------- |
| `idea` | 原始 backlog 条目——一时兴起想到的自嗨功能。尚未规格化;靠拷问(`/grill-with-docs`)变成真正的工单。 |

当技能提到某个角色(比如"打上 AFK-ready 的 triage 标签"),用上表对应的标签字符串。
